# Epistle 3

A single-file, browser-playable Half-Life fan game telling the full story of Marc Laidlaw's
"Epistle 3" letter — the crash on the ice, the trek to the *Borealis*, Mossman's rescue from
Combine detention, boarding the time-slipping ship, the argument at the console, the collision
course with the Combine nexus, the G-Man's extraction of Alyx, and the vortigaunts' claim on Gordon.
Built with Three.js. Desktop (mouse + keyboard) and iPhone (touch) supported.

**Play it:** https://lucbettaieb.github.io/epistle3/
